# SayOnce over a Sionna-simulated 5G NR uplink

Method and assumptions: [docs/sionna-5g.md](../../docs/sionna-5g.md).
Tables and figures: [summary.md](summary.md) (generated by `sionna_nr/analyze.py`).

| File | Contents |
|---|---|
| `bler.csv` | Sionna PHY: PUSCH transport-block error rate vs SNR, 9 MCS, TDL-C, 3 km/h, 2 RX antennas |
| `ue_links.csv` | Sionna SYS: 2000 UEs in a UMa cell: path loss, PRBs, transmit power, SNR, MCS, TBLER, uplink goodput |
| `profiles.json` | the 10th / 50th / 90th percentile UEs as emulator link profiles, plus all assumptions |
| `net.csv` | harness: 5 systems, 10/100 KB, 20 rounds, 3 repeats, over the three profiles (`mcp` workload) |
| `energy/` | radio energy per session (LTE RRC parameters of Huang et al. 2012 applied to the NR link) |
| `split_runs/` | the five parts `net.csv` was merged from (the run was split to save time) |
| `fig_bler.png`, `fig_uplink_cdf.png`, `fig_time.png` | figures |

## Commands used

Sionna 2.2.0 (`sionna-no-rt`), PyTorch 2.15 on CPU, Python 3.12, Linux, 2 cores.

```bash
pip install -e ".[dev,sionna]"

# Link level. MCS 3-14 with the defaults (up to 1000 blocks per point);
# MCS 17-27 with fewer blocks per point and starting closer to the waterfall, to save time.
python sionna_nr/link_level.py --mcs 3 6 9 11 14 --batch 200 --max-blocks 1000 --min-errors 100 --seed 42 --out bler_a.csv
python sionna_nr/link_level.py --mcs 17 20 --batch 100 --max-blocks 500 --min-errors 50 --snr-offset 0 --seed 43 --out bler_b.csv
python sionna_nr/link_level.py --mcs 24 27 --batch 100 --max-blocks 500 --min-errors 50 --snr-offset 1 --seed 44 --out bler_c.csv
# results/sionna_nr/bler.csv = the three files concatenated

# System level
python sionna_nr/system_level.py --bler results/sionna_nr/bler.csv --out results/sionna_nr --drops 40 --ues-per-drop 50

# SayOnce over the three links. One command works; we split it into parallel parts
# (the emulator mostly waits, so parts do not slow each other down) and merged them:
P=results/sionna_nr/profiles.json
python sionna_nr/run_sayonce.py --profiles $P --only nr-p10 --systems jsonrpc   --repeats 3 --no-energy --out results/sionna_nr/split_runs/p10_jsonrpc.csv
python sionna_nr/run_sayonce.py --profiles $P --only nr-p10 --systems cbor-full --repeats 3 --no-energy --out results/sionna_nr/split_runs/p10_cbor.csv
python sionna_nr/run_sayonce.py --profiles $P --only nr-p10 --systems jsonrpc-gzip json-delta sayonce --repeats 3 --no-energy --out results/sionna_nr/split_runs/p10_rest.csv
python sionna_nr/run_sayonce.py --profiles $P --only nr-p50 --repeats 3 --no-energy --out results/sionna_nr/split_runs/p50.csv
python sionna_nr/run_sayonce.py --profiles $P --only nr-p90 --repeats 3 --no-energy --out results/sionna_nr/split_runs/p90.csv
python sionna_nr/run_sayonce.py --profiles $P --out results/sionna_nr/net.csv --merge results/sionna_nr/split_runs/*.csv

python sionna_nr/analyze.py --dir results/sionna_nr
```

The emulator is deterministic for a given seed and the residual loss is at most
10⁻⁴, so the three repeats differ by at most 7 % (largest on the fast 90th-percentile link, where a run lasts about a second).

The token columns of `net.csv` were counted with the approximate tokenizer
(`tokenizer = approx`): tiktoken's `o200k_base` file could not be downloaded in the
environment that ran this experiment. Only bytes and times are used here; the
token results of the report come from `results/final_mcp/`.
